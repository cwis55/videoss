# 생생(@saeng_mag) 카드뉴스 템플릿

인스타그램 게임 카드뉴스용 1080×1350(4:5) 템플릿입니다. `preview/`에서 샘플 결과를 볼 수 있습니다.

## 사용법

게시물마다 `posts/<이름>/` 폴더를 만들어 씁니다. 예: `posts/catmail/`

1. `posts/<이름>/images/`에 스크린샷, `clips/`에 영상(1080×1350으로 자른 mp4)을 넣습니다.
2. `posts/<이름>/content.js`에 `CARDS`를 씁니다. 형식은 `posts/catmail/content.js` 참고.
   - `bg`: 배경 이미지, `video`: 영상 슬라이드로 만들 클립 (이 경우 `bg`는 정지 이미지용)
   - `*글자*`: 노란색 강조, `\n`: 줄바꿈
   - `price`: `{ sale }`만 쓰면 정가, `orig`·`off`를 넣으면 할인 표시
   - 카드를 넣고 빼도 페이지 번호(01 / 09)가 자동으로 맞춰집니다.
3. 내보내기
   ```bash
   npm i playwright          # 처음 한 번 (ffmpeg도 필요)
   node render.mjs catmail   # posts/catmail/out/에 01.png ... 생성, 영상 카드는 01.mp4도 생성
   ```
   브라우저에서 `template.html?post=catmail`을 열면 영상까지 움직이는 미리보기를 볼 수 있습니다.

## 카드 종류

| type | 역할 | 참고한 예시 |
|---|---|---|
| `cover` | 첫 장. 스크린샷 + 2줄 후킹 문구 + 생생이 "넘겨봐!" | 너겟(2톤 헤드라인), 루루코(작은 라벨 + 큰 제목) |
| `game` | 게임 정보: 번호, 이름, 출시일·평가·한국어, 할인가 | 게임서랍장(정보 블록), 게임큐레이션(취소선 가격) |
| `point` | 매력 포인트 1장에 1개 | 루루코(라벨 + 2줄 제목 + 1줄 설명) |
| `check` | "이런 사람한테 맞아요" 체크리스트 → 저장 유도 | 웹 검색 결과(저장할 가치를 주는 장) |
| `cta` | 공유 대상 지목 + 팔로우 카드 + 저장·공유·댓글 안내 (`event`를 넣으면 이벤트 상자 추가) | 루루코(친구에게 보내줘), 너겟(팔로워 이벤트) |

## 고정 브랜드 요소

- 컬러: 젤리 노랑 `#FFC61E`, 주황 `#FF8A00`, 할인 `#F25C05`, 크림 `#FFF6DC`, 초코 `#2B1608`
- 폰트: Pretendard(제목·본문), Jua(생생 이름·말풍선). 둘 다 무료 상업용(OFL) 폰트입니다.
- 모든 장 공통: 왼쪽 위 생생 프로필, 오른쪽 위 페이지 번호, 아래 `@saeng_mag` 워터마크, "넘겨보기 →"

## 릴스 템플릿

카드뉴스와 같은 색·폰트·생생 프로필·마스코트를 쓰는 1080×1920 릴스입니다.

- 화면 구성: 위쪽 제목 → 가운데 게임 영상(가로) + 흐린 배경 → 아래 자막. 인스타 UI가 덮는 위 150px, 아래 420px, 오른쪽 140px은 비워 둡니다.
- 장면 종류: `hook`(첫 장면, 생생이 "끝까지 봐!"), `info`(이름·가격), `point`, `outro`(노란 화면, 팔로우, 카드뉴스 안내)
- 자막은 줄마다 아래에서 통통 튀어 오릅니다.

```bash
node reel.mjs catmail      # posts/catmail/reel.js → posts/catmail/reel/out/reel.mp4
```

### TTS (ElevenLabs)

```bash
ELEVENLABS_API_KEY=... ELEVENLABS_VOICE_ID=... node tts.mjs catmail   # reel/voice/01.mp3 ...
node reel.mjs catmail      # 음성이 있으면 장면 길이를 음성에 맞추고 음성을 넣음
```
장면의 `say`(없으면 `sub`)를 읽습니다. 음악은 들어가지 않으니 인스타에서 붙여 주세요.
