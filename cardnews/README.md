# 생생(@saeng_mag) 카드뉴스 · 릴스 템플릿 (고정 v1)

게임 하나로 **카드뉴스(1080×1350)**와 **릴스(1080×1920)**를 같은 틀로 뽑습니다.
디자인·목소리·속도는 아래 값으로 고정합니다. 게시물마다 바꾸는 건 `posts/<이름>/`의 글과 영상뿐입니다.

## 새 게시물 만드는 순서

1. `posts/_new/`를 `posts/<이름>/`으로 복사하고, 두 파일 맨 위의 경로(`P`, `C`)를 바꿉니다.
2. 재료 넣기
   - 카드뉴스: `images/`에 스크린샷, `clips/`에 4:5로 자른 영상(선택)
   - 릴스: `reel/clips/`에 가로 영상 구간(1920×1080). 장면마다 하나씩, 멈춘 화면 없이
3. 글 쓰기: `content.js`(카드뉴스), `reel.js`(릴스)
4. 뽑기
   ```bash
   npm i playwright                          # 처음 한 번 (ffmpeg도 필요)
   node render.mjs <이름>                    # 카드뉴스 → posts/<이름>/out/01.png … (영상 카드는 .mp4도)
   NODE_USE_ENV_PROXY=1 node tts.mjs <이름>  # 릴스 음성 → posts/<이름>/reel/voice/01.mp3 …
   node reel.mjs <이름>                      # 릴스 → posts/<이름>/reel/out/reel.mp4
   ```
   브라우저에서 `template.html?post=<이름>` / `reel.html?post=<이름>`으로 미리보기도 됩니다.

## 올릴 때 멘트 (게시물마다 같이 만듦)

- `caption_cardnews.txt`: 길게. 후킹 제목 → 게임 이름 → 소개 → ✔️ 포인트 3개 → 가격 → 친구 태그 + 저장 유도 → 해시태그 8~10개
- `caption_reel.txt`: 짧게. 질문형 후킹 한 줄 → 게임 이름 → 인원·장르·가격 한 줄 → 친구 태그 → 해시태그 5~6개
- 확인 안 된 정보(출시일, 한국어 지원 등)는 쓰지 않음. 다른 게시물 언급 없음

## 글 쓰는 규칙 (공통)

- `*글자*`: 노란색 강조, `\n`: 줄바꿈
- 확인된 정보만 씁니다. 출시일·평가·한국어 지원은 확인됐을 때만 넣습니다.
- 가격: `{ sale }`만 쓰면 정가, 할인이면 `{ orig, sale, off }`
- 영상 속 자막·알림창 같은 글자는 블러 처리합니다(릴스는 장면의 `blur`).

## 카드뉴스 (고정)

| 순서 | type | 내용 |
|---|---|---|
| 1 | `cover` | 스크린샷(또는 영상) + 라벨 + 두 줄 후킹 제목 + 생생이 "넘겨봐!" |
| 2 | `game` | 이름, 정보 칩, 가격, 소개 두 줄 |
| 3~ | `point` | 매력 포인트 1장에 1개 (2~5장) |
| 끝-1 | `check` | "이런 사람한테 딱 맞아요" 체크리스트 → 저장 유도 |
| 끝 | `cta` | "○○ 좋아하는 친구에게 이 게임 보내줘!" + 팔로우 카드 + 저장·공유·댓글 (이벤트 없음) |

모든 장: 오른쪽 위 페이지 번호, 아래 `@saeng_mag`, "넘겨보기 →" (왼쪽 위 생생 프로필 배지는 없음)

## 릴스 v2 (현재 기본 · `layout: 'full'`)

조회수·이탈률 피드백으로 바꾼 구성입니다. (v1은 냥냥 우체국·Light Up The Town에 쓴 가운데 띠 레이아웃)
- 게임 영상을 세로 전체 화면으로 (장면마다 `fx`로 자를 위치 조절)
- 글자 최소: hook은 제목만(대사는 `say`로 읽기), point는 이모지 태그 + 자막 한 줄, 큰 제목 없음
- 첫 1초에 가장 눈에 띄는 장면 + 비교·궁금증·타이밍(예: "내일 출시") 후킹
- 15~20초, 엔드카드 1초(`endHold: 1.0`)로 반복 재생 유도
- 트레일러에 박힌 자막은 `REEL.blur`로 모든 장면에서 가림
- 카드뉴스: 8장 안팎, 설명은 한두 줄, 표지 라벨에 지금 봐야 할 이유(출시일·한국어 등)

## 릴스 v1 (고정)

| 순서 | type | 내용 |
|---|---|---|
| 1 | `hook` | 두 줄 후킹 제목 + 생생이 "끝까지 봐!" + 질문형 첫마디 |
| 2 | `info` | 이름 + 정보 칩 + 가격 (읽기만: `say`) |
| 3~ | `point` | 포인트 3~5개 |
| 끝 | `outro` | "재밌어 보이면 같이 할 친구 태그해줘!" + 팔로우 → 초코색 페이드아웃 → 생생 엔드카드 |

- 화면: 위 제목 → 가운데 가로 게임 영상(흐린 배경 위) → 아래 자막. 인스타 UI 자리(위 150 / 아래 420 / 오른쪽 140px)는 비움
- 모든 장면은 영상. 장면보다 짧은 클립은 살짝 느리게 재생해서 맞춤
- 자막: 줄마다 아래에서 통통 튀어 오름
- 속도: 음성 앞뒤 무음 제거, 대사 끝나고 0.15초 뒤 다음 장면, 장면마다 펀치 줌(0.3초), 엔드카드 1.8초
- 다른 게시물(카드뉴스 등) 언급하지 않음
- 효과음: `assets/sfx/pop.mp3`(장면마다 자막 첫 줄, 볼륨 0.35), `end.mp3`(엔드카드 폭죽). `whoosh.mp3`를 넣으면 장면 전환음
- 음악은 넣지 않음 → 인스타에서 붙이기

### 목소리 (`voice.json`)

ElevenLabs My Voices의 'You' · Eleven v4 · Stability 0.5 · Similarity 0.75 · 말 속도 1.12배(음 높이 그대로).
게시물에서 바꾸고 싶을 때만 `reel.js`에 `voice: { speed: 1.2 }`처럼 바꿀 값만 적습니다.
한국어 모드(`language: ko`)가 기본이에요. 영어 게임 이름은 "라이트업타운"처럼 한글로 붙여 써야 영어 발음이 안 섞여요.
음성을 만든 뒤에는 받아쓰기로 발음을 확인하고, 잘못 읽힌 단어는 쉼표를 넣는 등 `say`를 고쳐 다시 뽑습니다.
(예: "냥냥 우체국"이 "양양"으로 들려서 "이름은, 냥냥 우체국!"으로 고침)
