# 생생(@saeng_mag) 카드뉴스 템플릿

인스타그램 게임 카드뉴스용 1080×1350(4:5) 템플릿입니다. `preview/`에서 샘플 결과를 볼 수 있습니다.

## 사용법

1. 게임 스크린샷을 `images/` 폴더에 넣습니다.
2. `template.html` 맨 위의 `CARDS` 내용을 수정합니다.
   - `bg: 'images/파일.jpg'`: 배경 스크린샷 (`scene:0~3`은 샘플 배경)
   - `*글자*`: 노란색 강조, `\n`: 줄바꿈
   - 카드는 넣고 빼도 페이지 번호(01 / 06)가 자동으로 맞춰집니다.
3. PNG로 내보냅니다.
   ```bash
   npm i playwright        # 처음 한 번
   node render.mjs         # out/01.png, 02.png ... 생성
   ```
   브라우저에서 `template.html`을 열어 캡처해도 됩니다.

## 카드 종류

| type | 역할 | 참고한 예시 |
|---|---|---|
| `cover` | 첫 장. 스크린샷 + 2줄 후킹 문구 + 생생이 "넘겨봐!" | 너겟(2톤 헤드라인), 루루코(작은 라벨 + 큰 제목) |
| `game` | 게임 정보: 번호, 이름, 출시일·평가·한국어, 할인가 | 게임서랍장(정보 블록), 게임큐레이션(취소선 가격) |
| `point` | 매력 포인트 1장에 1개 | 루루코(라벨 + 2줄 제목 + 1줄 설명) |
| `check` | "이런 사람한테 맞아요" 체크리스트 → 저장 유도 | 웹 검색 결과(저장할 가치를 주는 장) |
| `cta` | 공유 대상 지목 + 팔로우 카드 + 이벤트 | 루루코(친구에게 보내줘), 너겟(팔로워 이벤트) |

## 고정 브랜드 요소

- 컬러: 젤리 노랑 `#FFC61E`, 주황 `#FF8A00`, 할인 `#F25C05`, 크림 `#FFF6DC`, 초코 `#2B1608`
- 폰트: Pretendard(제목·본문), Jua(생생 이름·말풍선). 둘 다 무료 상업용(OFL) 폰트입니다.
